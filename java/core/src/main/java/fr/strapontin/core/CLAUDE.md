# Correspondance floue (`fr.strapontin.core`)

`estDoublonSalle` (`core.CorrespondanceSalle`) : Levenshtein ≥ 0.75 ou containment de caractères | Jaccard tokens spécifiques > 0.5 | token pivot spécifique (≥ 7 chars, Jaccard > 0.3, au moins 2 tokens spécifiques de chaque côté depuis v3.0.1 — un nom réduit à son seul pivot rapprochait à tort deux salles distinctes d'une même ville) | égalité sans espaces (couvre une source qui omet l'apostrophe, ex. "LOlympia"/"L'Olympia") | containment de tous les tokens spécifiques du nom le plus court dans le plus long (≥ 4 caractères/token, ≥ 2 tokens spécifiques de chaque côté). "Tokens spécifiques" = tokens significatifs moins `MOTS_GENERIQUES_SALLE` (theatre, chateau, casino, colisee, expositions, culturel, metropole, municipal, antique, parc, barriere, eglise, saint… — "arena" volontairement absent, contributeur légitime ; "eglise"/"saint" ajoutés en v2.8.4, partagés par la quasi-totalité des édifices religieux, gonflaient à tort le Jaccard entre deux églises distinctes). Les critères par tokens ignorent le suffixe d'arrondissement qu'Eventim accole à ses lieux (« … paris 08 », v3.0.1 — il rapprochait par Jaccard/pivot deux lieux distincts d'une même ville, ex. Cathédrale Américaine / Notre-Dame) ; Levenshtein et containment restent calculés sur les noms complets (le retirer partout créait d'autres faux positifs à préfixe générique, ex. Église/Théâtre de la Madeleine — mesure sur 12 403 paires prod : aucune paire modifiée). Limites connues non couvertes : pivot nom de ville, Jaccard gonflé par un token court comme "des". `estDoublonSalle(nomA, nomB, pivotAutorise)` : `pivotAutorise=false` désactive à la fois le pivot et le containment de caractères (v2.8.4, le premier critère) — les deux plus faibles des cinq, un nom court peut être préfixe strict d'un nom plus long sans rapport (ex. "la prade"/"la pradella") — réservé aux cas sans aucun signal de localisation indépendant (voir `WikidataSalleSource`).

`estDoublonArtiste` : Jaro ≥ 0.95 (troncatures TM, ex. "aliz"/"alizee", "fawn"/"fawnn") | containment ratio ≥ 0.65 (variations longues, ex. "star academy"/"star academy 1") | égalité sans espaces (contraction de nom propre qu'une source omet, ex. "N'Dour"/"NDour") | préfixe de mot complet (le nom court, ≥ 2 mots, est un préfixe du nom long suivi d'une espace — ex. "earl sweatshirt" / "earl sweatshirt and mike", "jay z" / "jay z 30" — un co-tête d'affiche ou un suffixe de tournée ajouté par une seule source fait chuter le ratio de containment sous le seuil ; le garde-fou ≥ 2 mots exclut un prénom seul comme "mike" préfixe de "mike tyson"). `normaliserTexte` : `$` supprimé sans espace, `&` → `and`.

→ Détails et justification des seuils : [wiki Sources-de-données](https://codeberg.org/Kwaite/strapontin/wiki/Sources-de-donn%C3%A9es)
