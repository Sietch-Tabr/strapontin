# Front (Vue 3 + Vite)

⚠️ `npm run build` émet un warning `inlineDynamicImports option is deprecated, please use codeSplitting: false instead` (build du service worker, mode `injectManifest`) — dette interne connue de `vite-plugin-pwa` (déjà en dernière version 1.3.0, PR upstream #939 non mergée), pas une mauvaise configuration locale. `npm ci` en CI (`test-front`/`build-front`/`lint-front`) émet aussi 2 warnings `deprecated` sur `glob`/`source-map`, transitifs via `workbox-build` — non actionnables ponctuellement (`glob` plafonné par la contrainte `^11.0.1` de `workbox-build`, CVE-2025-64756 déjà patchée dans cette version et de toute façon hors vecteur d'exploitation, API JS seule utilisée jamais la CLI). Le mainteneur de `vite-plugin-pwa` a annoncé ([issue #933](https://github.com/vite-pwa/vite-plugin-pwa/issues/933), 13/09/2026) un fork complet de Workbox (340+ → ~20 dépendances) + écosystème `@vite-pwa/core`, avec abandon prévu de Google Workbox — ces trois warnings ne sont donc pas une dette figée en attente d'un correctif ponctuel, mais résoudraient tous à la racine une fois cette réécriture publiée (aucune date, aucun paquet publié sur npm à ce jour). Suivi en mémoire (`reference_vite_plugin_pwa_fork_933`), pas d'intégration au skill `check-deps`.
